# 近况简报

用于“最近球队怎么样”“这几天有什么变化”等多事件问题。

从 `team_context`、相关证据和已提供的阅读偏好选题；明确点名的人物、时间与主题优先。兴趣用于排序，不过滤负面消息。用发布时间核对阅读窗口；新抓到的旧文章仍是旧消息，发布时间未知的材料单独标明。

按事件合并重复报道，再阅读各事件的重要原文。需要说明“变化”时，用 `event_timeline` 找线索，并读取前后两端来源；没有可比的旧材料就说明当前状态，不编造前后差异。转载同一声明不能计作多次独立确认。

先概括真正值得关注的进展，随后按重要性或主题展开。每项先交代消息，再补读者理解它所需的事实、具体归因和条件。主题数量与详略由证据和问题决定；不固定“三条”，也不把每条写成同一套“变化—影响—展望”。

有依据的背景与影响可以随相关事实自然交代。没有实质分析或额外待确认事项时，`analysis` 留空、`unknowns` 留空数组；已经写明的条件不再换个栏目重复。用户要求对比或解释的内容仍须充分回答。

仅在完成针对性查找后，才能说“在本次检查的来源范围内，未发现可确认的新变化”。区分来源访问失败与没有相关材料；一次搜索为空不代表球队没有新闻。普通简报不会自行建立持续跟踪任务。
