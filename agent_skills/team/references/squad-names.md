# 球员中文名

本叶子把阵容上的英文显示名译成大陆中文名。翻译由本叶子的大模型完成。不查维基数据、维基百科或其他姓名来源。

`team-maintenance` 的 `names` 仍是「只能查、不能翻」。那条不适用于本叶子。

## 何时做

阵容快照里每一行都有 `provider_id` 之后才译。没有名单，或还有人缺少身份键，本叶子不动，等 `squad.info`。身份键齐了之后，可以和 `squad.images` 并行。

## 输入与写回

每人一条输入：`provider_id` 加上英文显示名。英文名只是待译文本，不能拿来认人。

写回必须按 `provider_id`。不要按姓名、号码或行序对上一个人。`provider_id` 对不上就不要写。不要调用 `maintain_team_data(parts=["names"])`，那条会去查外部来源。

译名用大陆习惯的简体中文。读法拿不准也照样写回。不要因为「译名可疑」留下这一条不写。不改国籍、生日、位置、号码或归属。

## 缺口

- 没有英文显示名可译：该球员记 `MISSING`，`retryable=false`。再跑一轮也译不出空字符串。
- 大模型调用失败：记 `MODEL_FAILED`，`retryable=true`。
- 本轮被打断：记 `INTERRUPTED`，`retryable=false`。不要把中断记成可重试。

共享原因码表里的 `MISSING` 表示「叶子还没有快照」，并且可重试。本叶子在球员身上用的 `MISSING` 不是那个意思，以这里的 `retryable=false` 为准。

## 拿满与停止

阵容上每个人都有非空中文名，或带着上面的原因码。全部已有中文名，或剩下的都是不可重试缺口时，本叶子停止。还有待译的人，或还有 `MODEL_FAILED`，才再派。
