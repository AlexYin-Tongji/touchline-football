# 阵容与姓名

本叶子负责名单，以及这份名单还缺姓名时的译名。姓名不是单独的叶子：只有阵容缺口确实需要姓名时才一并补。

## 先读

读当前阵容快照：人数、位置、号码、出生日期、归属，以及哪些人缺可显示的姓名。已有有效快照且未过期，就不要整表重取。

## 补什么

- 名单缺失或过期：`maintain_team_data(parts=["roster"])`。
- 名单在，但应有姓名的人仍空着：再 `maintain_team_data(parts=["names"])`。不要为了姓名重取整份赛程或照片。

来源暂不可用记 `SOURCE_UNAVAILABLE`，限流记 `RATE_LIMITED`，都可重试。范围不允许记 `SCOPE_DENIED`，不可重试。

## 拿满

阵容快照有效，且需要姓名的人都有来源姓名，或剩余缺口的原因码不可重试。不把失败显示成「没有球员」。不凭模型记忆补国籍、生日、位置或译名。
