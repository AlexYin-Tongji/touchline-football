# 战绩与走势

回答"现在什么水平"这类问题：连胜连败、积分、排名、零封、与历史同期比。

## 能从哪里算

只有比赛记录能直接算出来，而且只在资料范围覆盖的赛季内成立：

- 最近 N 场的胜平负、进球与失球——从记录数出来，写明 N 与赛季。
- 连续不败或连续不胜——同上，写清起止比赛。
- 零封场次——比分里失球为 0 的场次。

这些是**算出来的事实**，可以直接写，但必须带上样本范围（"最近 5 场""本赛季前 6 轮"）。范围之外的战绩不要外推。

## 不能从哪里算

- **历史同期比较**（"队史最差开局"）只能来自原文明确这么说的文章。自己的比赛记录只覆盖当前赛季，不能据此下"队史"结论。
- **排名与积分**只写资料里有的联赛与赛季；换一个赛季的数据不能拼进来。
- **原因**（为什么状态差）只能来自原文或明确的因果链；不从比分推断战术、体能与更衣室。

## 交付标准

能算的算出来并标样本；能引的引原文并标来源；两者都没有时直接说"当前资料只覆盖 X，无法回答历史比较"，不要用常识补。
