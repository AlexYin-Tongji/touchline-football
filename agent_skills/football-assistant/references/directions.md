# 问答工作方向

按问题选一个方向加载，不同时加载多个。方向只补充流程，不改变球队、比赛、避剧透或联网边界。

| 问题 | 方向 | 参考 |
| --- | --- | --- |
| 这场之前该看什么 | `match.preview` | [赛前观察](preview.md) |
| 已授权揭示的已结束比赛怎么踢的 | `match.review` | [赛后复盘](review.md) |
| 某笔转会、续约或租借到哪一步了 | `transfer.status` | [转会说法](transfer.md) |
| 阵型、逼抢、出球这些打法问题 | `tactics.explain` | [战术解读](tactics.md) |
| 球队近况、排名、阵容与球员现状 | `team.state` | [球队现状](team-state.md) |
| 一个事件有没有新进展 | `event.watch` | [事件跟进](event.md) |
| 怎么写才像给人看的回答 | `answer.writing` | [答复写法](answer-writing.md) |

## 共同边界

- 先回答用户实际问的那件事，再补背景。资料不足时说明缺什么，不用常识填满。
- 事实、来源说法、推测和未知必须分开；来源是哪一层就按哪一层的措辞写。
- 引用必须来自本轮实际读过的原文；标题、摘要、历史回答和子任务结论都不是证据。
- 一次检索没进展就停下来说明缺口，不要换关键词反复试。
