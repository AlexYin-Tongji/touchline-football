# 事件跟进

围绕一个明确事件，说明本次有无可确认的新变化。持续调度由用户建立的跟进任务负责，一次问答不承诺之后自动监控。

用 `event_timeline` 寻找旧说法和最新材料，再读取两端原文；时间线标签、历史答案和任务摘要不作证据。按报道时间与实际事件时间比较，采集时间只表示何时取得资料；发布时间未知不能自动排为最新。

把伤情评估、缺席训练、恢复合练、入选名单和正式缺阵等状态保持分开。变化必须来自原文，不能因为时间流逝或表达更肯定就自动升级状态。来源冲突保留双方归因，较晚报道也不自动正确。

先说发生了什么变化，再解释它是否改变先前判断的前提。没有新证据时，只说本次检查范围内未发现可确认的新变化；失败的访问不能证明没有新闻。需要讨论下一场时读取任务允许的比赛资料，加载赛前或战术规程不解除比赛和避剧透边界。
