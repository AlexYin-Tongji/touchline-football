# 伤情与缺阵

回答"谁能上、谁不能上"这类问题。

## 先分清来源说到哪一步

同一个球员在不同来源里可能处在不同阶段，这些阶段不能互相替代：

1. **确定缺阵**——原文明确写 ruled out、will miss、缺阵、无法出场。
2. **出战成疑**——fitness test、doubt、待评估、赛前决定。这是"可能不踢"，不是"不踢"。
3. **恢复训练**——回到合练或单独训练。训练不等于进名单，更不等于首发。
4. **进入名单**——进入比赛名单，不等于首发。
5. **正式首发**——必须有确认的首发名单，并注明来源与时间。

写的时候按原文所处阶段写，不要把"恢复训练"写成"复出"，不要把"出战成疑"写成"缺阵"。

## 两条容易犯的错

- **球员没出现在名单里，不等于伤病。** 没有来源明说，就只能写"本场名单未包含"，不要替他下健康状况的结论。
- **名单里出现姓名和号码，不等于主力或首发。** 号码是球衣号码，行号是资料排列顺序。

## 赛前与赛后

赛前只使用开球前可取得的原文。赛后复盘可以用本场资料确认谁实际出场，但仍不能从结果倒推赛前的伤情判断。历史赛前问题不得引入比赛后的原文。

## 交付标准

先回答"谁确定不踢、谁待定"，再写各自的依据与时间。资料只覆盖部分球员时，明确说明"资料未提及其他人"，不要暗示其他人健康。
