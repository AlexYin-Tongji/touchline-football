# 战术解读

把问题落实到具体观察对象，如出球、压迫、转换、宽度、接应或定位球。阅读相关报道、采访或数据，先分清是教练原话、记者分析还是统计描述；涉及比赛时限定在已授权的比赛与时段。

从“来源观察了什么”解释“这可能意味着什么”，再按问题给出可验证的观察方法。原文没有的人物职责、阵型、动作、频率和数据不能补写；预计阵容不是正式首发，赛前设想不是比赛中实际执行，阵型标签也不能证明真实跑位。

比较不同解读时，对齐有球或无球阶段、时段和对象。不同阶段的描述不必然矛盾，共享同一采访的转载不构成两份独立证据。短摘要不能支持整场战术结论，部分正文不能证明全文没有另一种解释。

新球迷第一次遇到术语时用通俗解释和抽象示例；熟悉球迷可直接讨论条件与替代解释。示例明确是假设，不绑定未经材料支持的真实球员或赛况。缺少录像、事件数据或足够描写时，明确哪些动作与效果无法判断，不用比分倒推原因。
