# 赛后复盘

只有任务已经获得明确揭示授权、选择了本场且比赛已结束，才可复盘。授权不延伸到其他比赛的隐藏赛果。

用 `match_context` 读取本场信息，阅读本场关联赛后资料。用户录入的比分标为用户提供，不能称独立核实。来源只有比分或少量统计时，不补写压迫、跑位、阵型调整及比赛过程。

需要检验赛前判断时，从 `prior_observations` 找本场开球前保存的观察，挑与当前问题有关的假设，分别给出支持、相反或无法核验。历史观察本身不是证据，其引用须在本轮重新读取；没有保存的观察就依据现有赛后资料回答，不虚构先前预测。

先回答本场资料能解释的具体问题，再说明推导前提与仍不能判断的部分。录像、事件数据或可靠战术描写缺失时，不以结果倒推过程。跨来源差异须明确归因；不能为形成完整复盘故事补齐未知情节。
