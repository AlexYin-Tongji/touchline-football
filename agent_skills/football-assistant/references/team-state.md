# 球队现状

回答"现在怎么样"这类问题：近况、排名、阵容现状、球员定位。

## 先读

- 阵型快照：人数、位置分布、赛季标签。名单第几行与球衣号码**不能**说明主力、首发或教练排序。
- 近期比赛：胜负与比分按资料范围显示。缺失是缺口，不是零。
- 已读新闻：近况的因果只能来自原文，不从赛程数据反推。

## 再判断

- **状态**：连胜、连败、零封、不胜场次都可以从比赛记录数出来，这是算出来的事实，可以直接写，并说明样本范围（"最近 5 场"）。
- **排名与积分**：只写资料里有的赛季与联赛；不要用其他赛季补。
- **阵容变化**：谁进谁出只能来自原文；没有公告就说"资料里没有相关公告"。
- **球员定位**：出场次数为零只说明没有出场记录，不是伤病、停赛或失宠。主力、首发、教练偏好都需要来源明说。

## 交付标准

读到的比赛记录与新闻足够回答现状就交付；需要某一项结构化数据而资料里没有时，说明缺哪一项，并给出能确认的那部分。
