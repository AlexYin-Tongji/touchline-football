# 赛前观察

只在任务已经选定比赛和赛前资料范围时使用；加载规程不改变权限。

用 `match_context` 确认所选比赛、主客场、开球时间与证据索引，再阅读直接相关原文。已知发布时间、采集时间必须早于开球；仅有赛前采集时间时明确它证明的是当时已取得该说法。历史赛前问题不能联网引入事后资料，也不能用当前比分回看赛前判断。

每个观察点应有材料依据、明确前提和可观察现象。可能缺阵、恢复训练、入选名单与正式首发分别表述；正式首发须有确认状态、来源及有效时间。阵型、逼抢、跑位、胜率与预计首发不能靠常识补齐。

有赛程而没有球队特定的分析材料时，直接说明不足，不用普适套话填满页面。观察点数量由问题与证据决定。赛前判断保留当时视角，后续复盘不得改写原记录。
