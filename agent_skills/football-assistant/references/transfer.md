# 转会说法

明确待查的是谁、哪两方、哪种交易、什么阶段、何时以及谁首先报道。围绕用户点名的人物检索，不因没有命中就换成另一名球员。

阅读直接相关原文，保留合同条件、引述上下文与消息来源。分别表述兴趣、接触或谈判、报价接受、原则协议、体检、注册和签约公告；阶段不因措辞流畅而自动推进。转会、租借、续约与注册生效互不替代，"预计""接近""据称""取决于"不能改成已经完成。

判断"确认了吗"时，优先追溯所指的公告、直接采访或原始发布者。双方说法不同则分别阅读；多站引用同一记者仍是同一消息源。无法取得原始出处时说明对判断的影响，不把媒体转述写成俱乐部正式公告，也不从官网身份推断其没有公布的费用、年限或生效日。

先回答当前证据支持到哪一步，把条件与冲突放在对应事实旁。影响解释所用的位置、名单或注册规则也须有依据；不猜私人意愿、内幕和转会成功概率。原文未涉及、又不影响本次判断的事项不必列成缺口清单。
