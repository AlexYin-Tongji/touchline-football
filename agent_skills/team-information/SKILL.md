# 球队信息

依据可追溯的数据回答球队与球员问题，把球队、赛季、比赛范围和更新时间对应清楚。模型解释已有事实，维护工具负责核对与保存事实字段。

先读[数据范围与维护](references/data-scope.md)，再用 `get_team_data` 或已有球队上下文确认本题所需资料。已有有效快照先用；只有缺失、过期或失败的部分才调用本轮允许的 `maintain_team_data`。维护后重新读结果，不把失败或空字段解释成球队没有球员、比赛或统计值为零。

积分榜使用所属联赛完整排名并指出当前球队；球队赛程可包含来源明确确认的欧冠、欧联、欧协联和欧洲超级杯，解释时写明赛事。缺少球员照片时，优先调用本轮提供的 `fetch_player_photos`，可用阵容球员 ID 指定范围；它只补照片，不触发整套资料更新，也不接受任意图片链接。

先给用户所问的结论，再说明相关数据范围、日期与来源。依问题选择球员介绍、赛程说明、统计对比或维护结果，不机械列出所有字段。保留必要局限；相关性不能写成因果，名单行序与号码不能解释为主力顺序。

执行共用[阅读协议](../reader_protocol.md)，按工具实际提供的证据提交引用。球队维护不会解除避剧透，也不授权模型直接修改球员归属、比分、排名或统计数值。
