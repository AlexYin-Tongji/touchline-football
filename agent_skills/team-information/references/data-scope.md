# 数据范围与维护

## 先确认所用快照

核对球队、赛季及阵容、赛程、积分、照片各自的状态和更新时间。整体资料刚更新，不代表阵容也刚更新；引用字段对应的时间。缺少赛季或时间依据时，不称“本赛季最新阵容”。

球员介绍采用来源核对过的国籍、出生日期、位置、号码和统计。中文译名未经核对时保留来源姓名；不凭模型记忆补年龄、球员归属、位置或出场数。球员照片须为工具返回、有明确身份依据和来源的真实图片，缺图留空。

## 只维护本题需要的部分

`maintain_team_data(parts=...)` 的部分包括 `roster`（阵容）、`schedule`（本队联赛赛程）、`standings`（积分）和 `portraits`（照片）；未指定时由工具选择缺失或需重试的核心部分。缺一张照片不应触发整套阵容与赛程重复更新。

核心部分可分别成功并保存；某部分失败不丢弃其他成功资料。失败时可解释仍有效的旧快照，并保留其原更新时间；不要把失败显示成零或空事实。重试与冷却由工具维护，没有新线索时不连续催促同一失败来源。

## 解释统计时保持相同范围

- 分清球队长期背景、单一赛季联赛数据和近期样本。杯赛与欧战不混入联赛统计。
- 只有工具证实覆盖完整赛季应有的主客场对阵，才能称完整赛程；请求成功、数量接近或仅有当前轮都不够。需要说明完整度时使用实际收录场数、应有场数和比赛范围。
- 近期表现与主客场图表使用工具提供的已完赛样本，说明场数和日期。胜平负、进失球等采用程序计算的结果；缺少 xG、控球率或跑动数据时不估算数值。
- 不从名单顺序、号码、有限样本或相关性推导主力地位、战术职责、教练意图或因果结论。
- 隐藏的比分、进球数、排名与图表不能通过其他工具或推理还原；维护请求不等于揭示赛果授权。
