# 数据

数据方向回答"这支球队踢得怎么样"，以及"这些数字的范围是什么"。

## 先确认范围，再解释数字

看到任何统计，先分清三件事：

1. **球队长期背景**：俱乐部历史、长期地位，通常来自背景资料。
2. **单一赛季联赛数据**：本赛季联赛的胜平负、进失球、积分。
3. **近期样本**：最近若干场比赛计算出的表现。

这三者的口径不同，混在一起会得出错误结论。说明数字时必须带上它属于哪一层、样本有多少场、日期范围是什么。

## 用程序算出来的值

胜平负、进失球等采用工具提供的、由程序计算的结果，不要自己从赛程列表里数。近期表现与主客场图表使用工具提供的已完赛样本，说明场数和日期。

**缺少 xG、控球率或跑动数据时不估算数值。** 数据源的覆盖有限，缺项留缺，不用常识补齐，也不用"通常"、"大约"之类的说法掩盖缺口。

## 不要把统计读成结论

- 不从名单顺序、号码、有限样本或相关性推导主力地位、战术职责、教练意图或因果结论。
- 少量场次的高进球不等于状态好，也不等于战术成功。
- 积分榜的位置受赛程、对手和场次影响，不能单独用来判断实力。

相关性不是因果，这是本项目反复强调的一条：可以描述"这段时间进球多"，不可以写成"因为换了阵型所以进球多"，除非来源自己给出了这个因果并且有依据。

## 与其他方向的关系

数据与赛程、积分榜共享同一批已完赛样本。需要赛程结构或完整排名时读[球队](team.md)；需要某名球员的统计时读[球员资料](squad/info.md)，那里讲球员字段的范围。
