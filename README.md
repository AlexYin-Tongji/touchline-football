# 看台 · V7

一个保存在自己电脑里的个人足球 Agent。打开浏览器就能看中文消息、了解球队与球员、向助手提问；不需要部署网站，也没有社区账号、发帖或评论系统。

## 三个入口

- **动态**：按球队阅读中文消息流，消息可带真实来源配图；展开后仍是中文内容，在相关位置点击链接打开原始来源。支持主题筛选、翻页和围绕消息追问。
- **球队**：球队介绍、当季球员与基础简介、有来源的球员照片、日程、积分、近期进失球和主客场表现图表。资料由后台定期维护，Agent 可通过技能查询和更新；数值以数据源为准，不让模型编写比分。
- **助手**：直接对话，也可从今日速览、比赛前瞻、赛后复盘、转会核验、战术讲解、球队与球员画像进入。比赛上下文和会话所选模型会保留。

设置只保留模型。来源配置、采集调度、工具预算、核验流程和数据维护由程序管理，不再放进用户设置。

## 打开使用

Windows 双击 `启动看台.cmd` 或已有桌面快捷方式，打开 **http://127.0.0.1:8765/**。

模型配置参考 DeepSeek 官方 Harness 的简洁流程：添加服务商 → 填写地址、协议和密钥 → 获取或手动添加模型 → 选择使用。支持 Chat Completions、Responses 和 Anthropic Messages。旧模型配置会自动迁移，密钥不回显。

“功能分工”可分别选择球队动态、足球对话和球队资料解读的模型。对话记录按球队保存，刷新后可恢复；已有对话继续使用原来的模型。球队选择器可直接关注多支球队。动态中的等待提示会说明排队、失败、待配置或额度原因，刷新可重试失败任务。

第一次请选择关注球队并配置模型。球队数字资料与消息来源自动更新；中文消息整理和问答使用你配置的模型。模型 API 是否收费取决于提供方；本地运行本身不收托管费，也不植入广告。

## 保存与来源

本机 `data/` 保存中文内容、对话、球队数据、关注选择和加密模型凭据。外部新闻仅持久保存标题、链接、日期、内容哈希及必要引用记录；正文在需要时临时读取，内存缓存自动过期，不再建立英文文章阅读库。用户手写的记录不会被清理。

已有有效中文报告、个人记录和模型配置会迁移保留。兴趣变化只影响后续选题，不抹掉历史消息；来源真正变更、删除或隐私范围变化仍会阻止失效内容展示。需要重新引用时会重新读取来源，打不开时如实说明。

五大联赛支持 2026/27 的 96 支球队，现有联赛、赛季、成员关系、赛程和积分结构继续使用。阵容与照片按球队维护；原站没有照片时保留占位，不生成假球员肖像。来源可能改版或限流，程序保留上次有效快照与更新时间。

## 开发与检查

需要 Python 3.11+、Node.js 22+：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm ci
npm run build
.\.venv\Scripts\python.exe -m uvicorn server.main:app --host 127.0.0.1 --port 8765
```

开发前端使用 `npm run dev`，其 API 代理到 8765。

```powershell
python -m unittest discover -s tests -v
npm run build
```

GitHub Actions 还检查 Linux 环境和 Docker 构建。Docker / Render 文件保留作可选服务器运行方式，不是个人版本的使用前提。
