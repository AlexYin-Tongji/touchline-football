# 看台 · V7.5

一个保存在自己电脑里的个人足球 Agent。打开浏览器就能看中文消息、了解球队与球员、向助手提问；不需要部署网站，也没有社区账号、发帖或评论系统。

## 三个入口

- **动态**：按球队阅读中文消息流，消息可带真实来源配图；展开后仍是中文内容，在相关位置点击链接打开原始来源。支持主题筛选、翻页和围绕消息追问。
- **球队**：球队介绍、当季球员与基础简介、有来源的球员照片、日程、积分、近期进失球和主客场表现图表。资料由后台定期维护，Agent 可通过技能查询和更新；数值以数据源为准，不让模型编写比分。
- **助手**：直接对话，也可从今日速览、比赛前瞻、赛后复盘、转会核验、战术讲解、球队与球员画像进入。比赛上下文和会话所选模型会保留。

设置只保留模型。动态、对话、球队解读、原文核验可以选择不同模型；未单独指定核验模型时，跟随当前任务模型。独立新闻可以并行整理，后台统一控制请求并发、去重、取消与失败重试，核验通过后才发布。来源配置和调度由程序管理。

主助手可以按问题需要创建多个子助手，并行研究或整理资料，等待结果、补充要求或停止分支。主子助手共用一套执行流程，子任务只接收必要背景，继承当前资料范围和联网权限。子结果仍需由主任务读取原文、核对后交付；简单问题无需分派。详见 [V7.2 通用智能体运行](docs/AGENT_RUNTIME_V7_2.md)。

V7.3 将工作规程整理为球队动态、球队信息、问答助手三个标准技能，旧任务模式继续兼容。新闻正稿按事件自然展开，不强制附加泛泛分析或关注清单。来源增加经过验证的BBC足球订阅与天空体育阿森纳订阅；指定资料并行读取，核验仅消除重复输入，保留完整的事实检查。详见 [技能、来源与质量优化](docs/SKILLS_TOOLS_V7_3.md)。

动态和球队页各有“启动／结束”：一次启动执行一轮，完成即结束，不再定时循环。结束会清理本功能的当前任务和后代，保留已有内容。刷新页面和服务重启不启动采集或模型。球队页提供完整所属联赛积分榜、欧战赛程及按身份核对的球员照片；动态新增 AS 与阿根廷 TyC Sports，详见 [V7.5 工具与技能验收](docs/TOOLS_SKILLS_V7_5.md)。

## 打开使用

Windows 双击 `启动看台.cmd` 或已有桌面快捷方式，打开 **http://127.0.0.1:8765/**。

模型配置参考 DeepSeek 官方 Harness 的简洁流程：添加服务商 → 填写地址、协议和密钥 → 获取或手动添加模型 → 选择使用。支持 Chat Completions、Responses 和 Anthropic Messages。旧模型配置会自动迁移，密钥不回显。

“功能分工”可分别选择球队动态、足球对话和球队资料解读的模型。服务商内部 ID 自动生成，显示名称可用中文。对话记录按球队保存，刷新后可恢复；已有对话继续使用原来的模型。球队选择器可直接关注多支球队。

动态页点击“启动”先接续已有待处理消息，再查找新来源、整理并核对，完成稿陆续加入动态；点击“结束”停止本队动态跟进。球队页独立启动阵容、赛程、积分和照片的来源维护，事实更新无需模型编写数字。模型根据问题与证据决定内容覆盖和详略，不设每日整理次数或默认答复条数。也可以在“问助手”中整理某个主题，结果保存在对话中。

第一次请选择关注球队并配置模型。点击启动更新球队资料与消息来源；中文消息整理和问答使用你配置的模型。模型 API 是否收费取决于提供方；本地运行本身不收托管费，也不植入广告。

## 保存与来源

本机 `data/` 保存中文内容、对话、球队数据、关注选择和加密模型凭据。外部新闻仅持久保存标题、链接、日期、内容哈希及必要引用记录；正文在需要时临时读取，内存缓存自动过期，不再建立英文文章阅读库。用户手写的记录不会被清理。

已有有效中文报告、个人记录和模型配置会迁移保留。兴趣变化只影响后续选题，不抹掉历史消息；来源真正变更、删除或隐私范围变化仍会阻止失效内容展示。需要重新引用时会重新读取来源，打不开时如实说明。

五大联赛支持 2026/27 的 96 支球队，现有联赛、赛季、成员关系、赛程和积分结构继续使用。阵容与照片按球队维护；原站没有照片时保留占位，不生成假球员肖像。来源可能改版或限流，程序保留上次有效快照与更新时间。

## 开发与检查

需要 Python 3.11+、Node.js 22+：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -c requirements.lock.txt
npm ci
npm run build
.\.venv\Scripts\python.exe -m uvicorn server.main:app --host 127.0.0.1 --port 8765
```

开发前端使用 `npm run dev`，其 API 代理到 8765。

```powershell
python scripts/check.py --suite fast
# 修改某个模块时只跑相关回归，例如：
python scripts/check.py --module test_team_refresh_parts test_team_center
# 交付前完整检查：
python scripts/check.py --suite full --json output/test-results.json
npm run test:ui
npm run build
```

GitHub Actions 还检查 Linux 环境和 Docker 构建。Docker / Render 文件保留作可选服务器运行方式，不是个人版本的使用前提。

快速套件不替代完整回归。检查入口会优先使用本项目 `.venv`，并列出最慢的用例。前端行为回归覆盖慢请求下的草稿和切队等操作；字体与布局通过桌面及窄屏实际浏览器检查。Python 依赖用 `requirements.lock.txt` 固定已验证版本，升级依赖后应重跑完整检查。

优化前的源码已保存在标签 `v7.0.0`，主线包含后续改进。涉及旧数据迁移时，程序先在 `data/backups/` 保存一致性数据库及配套 `.key`；回退代码前也应单独备份当前数据，Git 标签不包含个人数据库。
