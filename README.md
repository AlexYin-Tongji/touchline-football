# 看台 · V5

一个替你持续跟队、阅读原始报道、用证据解释足球的私人 Agent 网站。

V5 采用浏览器 / 服务器架构：React + TypeScript 提供页面，Python + FastAPI 负责资料采集、Agent 工具循环、原文核对、定时跟进与存储。浏览器不保存模型密钥；数据与球队静态素材由服务器提供。部署方案为 **Render Docker Web Service + 持久磁盘**，也可使用自己的 Docker 服务器。

## 这轮改动

- **私人网站**：访问密码、可退出的会话、同源修改校验、服务器运行状态；服务器模式不再提供 Windows 自启和桌面快捷方式。
- **球队资料库**：30 支常见球队，中文背景、官网、真实本地队徽和素材出处。只在首次导入或受控升级时补基础资料，保留用户修改；球队数量不等于官方赛程适配器数量。
- **真正阅读报道**：一级“资料阅读”页、标题与正文搜索、来源筛选、分段阅读、阅读字号、来源与时间信息、正文完整度标识。每篇资料可以直接交给助手追问。
- **采集与工具**：RSS 摘要可跟读同源原文；失败保留摘要和原因。长文分页阅读、正文段落定位、已读来源比较、个人阅读偏好工具，继续维护实际已读引用与避剧透边界。
- **个性化**：关注兴趣、球迷熟悉程度、阅读语言偏好和简报时间范围；新增“转会核验”和“战术解读”，共 7 个可组合技能。
- **交互**：球队搜索选择、常关注球队快捷切换、动态 / 阅读 / 助手三级导航、移动端适配、站内查看来源和文章上下文。

## 部署到 Render

完整步骤见 [部署与迁移说明](docs/DEPLOYMENT.md)。仓库已提供 `render.yaml`、多阶段 `Dockerfile`、`compose.yaml` 和 `.env.example`。

1. 将仓库推送到你自己的 Git 远端，在 Render 创建 Blueprint 并连接该仓库。
2. Render 读取 `render.yaml`，构建前后端并挂载持久磁盘。
3. 在 Render 的 Environment 中查看自动生成的 `TOUCHLINE_ACCESS_PASSWORD`，通过网站访问密码登录。
4. 在网站设置里配置模型、关注球队和资料来源，再开始采集。

这是一套私人网站，不包含公众注册或多账户隔离。Render 持久磁盘需要付费服务，本配置使用 Starter 及 1 GB 磁盘；创建服务前以平台显示费用为准。没有连接托管账户或远端仓库时，部署配置不等于网站已经上线。

## 本地运行

已有的 Windows 启动方式继续可用：`启动看台.cmd`、桌面快捷方式或 `./start.ps1`。本机入口为 **http://127.0.0.1:8765/**。既有 `data/` 数据会就地读取，目录不进 Git。

开发环境需要 Python 3.11+、Node.js 22+：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm ci
npm run build
.\.venv\Scripts\python.exe -m uvicorn server.main:app --host 127.0.0.1 --port 8765
```

前端开发另开终端 `npm run dev`，Vite 将 `/api` 代理到 8765。Docker 预览则复制 `.env.example` 为 `.env`，设置至少 16 位访问密码，再运行 `docker compose up --build -d`，打开 **http://localhost:8765/**。

## 使用

第一次可在明确标注的虚构示例中熟悉界面，然后切换真实资料。关注球队、添加 RSS / 网页来源或手动导入原文；用“更新动态”采集消息，打开“资料阅读”细读。在文章内选择“问助手”，可以追问依据、比赛影响或不同来源之间的差别。

模型支持 Chat Completions 和 Responses 兼容协议。请使用提供方实际公布的服务地址与模型 ID。分级连接检查会测试文本、工具调用和结果续答，并消耗少量模型额度。不会把纯文本连通误报为工具可用，也不会在真实资料失败时填入示例消息。

定时更新和主题跟进只在服务运行时执行；Render 服务器运行后不再依赖你的电脑开机。自动生成解读默认关闭，启用后会消耗模型额度。登录会话重启后失效，但数据库、加密密钥和偏好随持久磁盘保留。

## 数据与能力边界

球队背景与定时新闻分开存储；队徽用于识别球队，商标与原始素材权利归原权利人。网页正文只显示合法可取得的公开内容，不绕过付费墙或登录。标记“已提取正文”表示解析覆盖，不代表独立核实或保证原站全部内容已收录；无法取得的内容会标记为摘要、部分正文或失败。

官方赛程 / 比分适配器仍为阿森纳、利物浦、巴塞罗那、国际米兰；其余球队有背景、素材和来源入口，比赛可手动导入，不伪造赛程。部分站点限流、动态渲染或改版会影响采集。

避剧透会过滤赛果资料并提供部分安全节选；规则可能遗漏隐含表达。明确的赛后复盘仅可读取所选比赛范围。原文核对能减少无依据结论，但不等同于足球事实认证。

数据库与 `.key` 文件必须一起备份；密钥用于解密保存的模型凭据。不要提交或分享 `data/`、`.env` 或备份。运行时会向你配置的模型提供方发送问题、偏好与必要资料。
