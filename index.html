02

球队 THE CLUB

资料、一线队名单与有来源的照片、赛季表现、积分榜、胜平负与主客场、未来赛程。数值以数据源为准，缺的就留空。

96 支五大联赛球队照片须有来源更新记录
两名候选人出生日期差一年，继续拒绝挂图

模型不找图、不选 URL，匹配由确定性工具完成
射手、助攻、门将扑救分三张榜，不合并
03

问助手 THE ASSISTANT

直接对话，或从今日速览、比赛前瞻、赛后复盘、转会核验、战术讲解进入。回答带引用，引用只来自这一轮真正读过的原文。

带引用的回答中文问句命中英文来源子助手并行
引用必须来自本轮实际读过的阅读快照
搜索摘要、历史记录、子任务摘要不自动取得引用资格
避剧透删去的段落不能被引用
子助手只作线索，主任务引用前仍读原文
03 / Principles

三条不妥协的原则

不是功能列表，是每一次取舍的依据。它们来自用真实 bug 换来的边界。

我们整合信息，不认证真伪。你看到的是「谁在什么时候说了什么」——真伪由你判断。

01

整合信息，
不裁决真伪

DELETE ONLY WHAT ISN'T THIS CLUB'S

不盖“已核实”的章，也不因为无法确认就删掉一条消息。只删除不属于本队的内容，并数清删了什么。

02

来源分层决定
说话方式

TIER SETS TONE, NOT STATUS

官网直接陈述，媒体写“据 X 报道”，社区写“社区有说法”并附认同量。社区源不是低一等的媒体源，它的价值在时效与现场性。

03

模型解释，
不编造

WHEN UNSURE, LEAVE IT BLANK

比分、阵容、成员关系、照片都来自可追溯的采集。缺数据就留空，不生成假肖像，也不让模型改写事实字段。

05 / Get started

在你自己的电脑上跑

需要 Python 3.11+ 与 Node.js 22+。Windows 下双击启动脚本即可，其余平台按终端里的四步执行。

touchline — powershell 
# 1 · 准备环境
PS> python -m venv .venv
PS> .\.venv\Scripts\python.exe -m pip install -r requirements.txt -c requirements.lock.txt

# 2 · 构建页面
PS> npm ci
PS> npm run build

# 3 · 启动服务
PS> .\.venv\Scripts\python.exe -m uvicorn server.main:app --host 127.0.0.1 --port 9080
→   http://127.0.0.1:9080/

# 4 · 设置里填模型服务商 → 关注球队 → 动态页点「启动」
