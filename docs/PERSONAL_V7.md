# V7：个人足球助手

本轮将产品收拢为“动态、球队、助手”三个入口。本地运行是默认交付方式，GitHub仅管理代码；没有社区用户、帖子、评论或社交系统。

## 主要实现

- 中文动态按来源发布时间呈现，支持消息图片、展开阅读、来源超链接、按主题筛选和稳定游标翻页。
- 移除英文正文阅读库和运营设置。外部新闻正文仅有20分钟、4MB、最多96份的进程内缓存；SQLite保存元数据、哈希、必要引文与中文结果。重启后引用新闻会重新读取来源。
- 迁移同时核对旧报告来源和生成记录。阅读兴趣与篇幅偏好不再使旧中文稿失效，内容变化和权限变化仍会使其失效。没有充分旧证据的报告不会凭状态标签恢复。
- 研究工具组合官网、媒体RSS、新闻搜索与ESPN索引；候选保留来源覆盖和失败信息，并分页优先读取未处理资料。已读引用、球队范围、日期和联网边界继续验证。
- 球队中心按明确联赛赛季读取阵容、球员基础介绍与照片来源，聚合赛程、积分、近期战绩和主客场图表。`team_maintenance`技能调用查询和维护工具；模型解释资料，不改写源数据。
- 巴萨官方目录采用规范化全名+球衣号码的唯一匹配，真实验证29人中26人可补照片。其他缺图球员继续占位，不把相关新闻图冒充肖像。
- 模型配置参考DeepSeek官方Harness：服务商卡、Base URL、协议、密钥、模型列表获取和手动添加、选择当前模型。支持三种协议；旧凭据迁移；密钥不回显、不同来源不转送旧密钥。
- 对话锁定首次模型，切换模型开启新会话。比赛按钮从联赛记录解析到当前球队的比赛上下文，后续追问继续保留该范围。

## 本轮实际验证

- 真实联网研究查询找到多条相关候选，记录官网、媒体及搜索覆盖。
- 使用已有模型在隔离库成功生成一条2节中文短消息，含1张原站配图与正文中的配图，独立原文核对通过。SQL检查外部新闻全文持久化记录数为0。
- 五大联赛各选一队进行真实阵容接口校验，全部取得明确2026/27赛季响应。
- 模型配置、三协议工具往返、历史迁移、权限/图片边界、分页、队伍隔离、维护任务去重与会话绑定均有自动回归。
- 桌面和390px手机实际操作覆盖三个页面、球员资料与照片、消息来源直链、模型增删/手动模型、聊天入口及图表。测试使用隔离数据库，不额外提交付费模型调用。

本地完整回归已通过378项测试，前端生产构建通过。赛程接口同时支持比分板和球队已赛/待赛接口回退；巴萨实测38场（5已赛、33待赛），图表与积分口径5/5一致，保留26张官网照片。模型设置与三个主页面在1440px和390px实际浏览器验收无控制台错误或横向溢出。GitHub CI结果另以仓库实际运行记录为准。图片及原始数据的核验范围保持透明：接口不可用时保留旧快照并标明时间，图片不存在时不造图。

## 保留与边界

本机数据库、模型凭据与一次升级备份均不进入Git。旧手写记录和中文内容保留；旧原文不再在产品中展现。代码推送到新建私有仓库，原公开仓库未改。免费托管比较见 [FREE_HOSTING.md](FREE_HOSTING.md)。

模型服务仍可能收取调用费用，本地运行不等于模型免费。后台有并发、超时、重试及生成次数限制；这些实现细节由程序负责，不放进普通用户设置。
