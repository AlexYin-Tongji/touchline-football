# V4 改动与验证

验证日期：2026-09-10。

## 页面与使用方式

- 主导航只保留「球队动态」「询问助手」。赛程、近期表现、消息分类和球队背景集中在动态页。
- 设置以弹窗打开，包含使用偏好、球队资料、资料来源和关注主题。模型配置及原有数据保留。
- 统一中文字体与字号层级；球场卡片支持轻微立体倾斜，队徽悬浮，页面与卡片有过渡动画；遵守系统减少动态偏好。
- 不展示工具轨迹、模型参数、核对草稿和原文正文。消息与回答保留必要的待确认提示，来源使用超链接。
- 比赛前瞻、复盘支持连续追问；同一会话保留比赛范围。日期已知但时间未定的赛程不强行使用要求精确截止线的前瞻流程。

## 本地资料

- 四支内置主队补齐中文简介、昵称、城市、成立年份、球场、官网、队徽和资料出处。升级只填不存在的字段，不覆盖用户修改。
- 球队资料可在界面编辑。GET/PATCH `/api/teams/{id}/profile` 提供查询和部分更新。
- `public/assets/clubs/catalog.json` 包含 20 支常见球队的中文名称、别名和本地队徽；`attribution.json` 保留官方出处、原始地址及哈希。该目录仅表示图标可用范围，不作为当前联赛成员名单。
- 助手读取的原文及对话继续持久化到 SQLite；有实际已读来源的结构化消息另存 knowledge，保留引用、时间和支持程度。分析推测不作为事实归档。
- 动态卡片优先使用与当前来源版本一致的已归档中文要点。旧回答没有完整来源版本证明时，不回填为当前已核对事实；重新整理后逐渐建立新归档。
- 已新增按球队/资料模式查询的数据库索引。

## 采集工具

- 本地和联网检索支持消息分类、最近 N 天以及中文球员、对手、战术关键词。
- 新增来源概览工具，提供来源状态和新鲜度。
- 索引缓存 10 分钟，原文复用 20 分钟；网络失败可使用 24 小时内的旧索引，保留真实时间及回退标记。
- 跟踪参数归一化去重；排除明显的女足、青年队内容混入男足一线队；缓存仍检查来源启用状态、许可域名和球队/比赛范围。

## 验证结果

- `python -m unittest discover -s tests`：201 项通过。
- `npm run build`：TypeScript 检查及生产构建通过。
- 真实卫报阿森纳公开订阅源：读取并解析出 20 条带发布时间的消息。
- 20 个本地队徽与官方目录标题及原始文件哈希对应，未发现脚本、事件属性或外部资源引用；263 项名称/别名及未知球队回退检查通过。
- 浏览器：验证主导航、球队切换、比赛复盘、连续追问、刷新后保留两轮显式复盘、设置弹窗、资料编辑保存和撤销后的再次保存。
- 浏览器：来源详情不显示正文；嵌套弹窗的 Escape 只关闭最上层，滚动锁恢复正确。
- 浏览器：桌面及 390px 手机布局、无横向溢出、系统减少动态设置生效。检查期间浏览器控制台无错误。
- 浏览器测试使用独立 `output/v4-qa-data` 数据库，不改正式资料或模型配置。
- 正式服务已切换为 4.0.0；确认 4 队基础资料完整，原有 78 份可见真实资料、10 条事件及模型配置仍可读取。升级前数据库备份位于 `data/backups/touchline-before-v4-*.sqlite3`。

## 已知范围

内置自动采集仍覆盖阿森纳、利物浦、巴塞罗那、国际米兰；对手队徽目录并不自动提供这些球队的采集适配器。未增加付费信息服务，也未对每个官网逐一执行完整实时采集。真实模型全链路以现有协议测试覆盖，本轮浏览器使用演示回答，没有调用用户的付费模型。部分来源可能限流或不可读；不会用演示消息补入真实空间。
