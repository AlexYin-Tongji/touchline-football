- 真实/示例及不同球队的资料、运行和历史隔离。

- 赛前证据的发布时间/采集时间边界；显式本场复盘；隐藏关联资料在编辑时保留。
- 配置字段校验、密钥加密与响应脱敏、模型服务 origin 变化时不复用旧密钥。
- HTML/RSS/Atom/JSON-LD 解析、未知时间、私网与重定向拒绝、DNS 地址固定。

- 未配置模型、无原始证据、无效引用、一次修复、轮次/时间上限和故障状态。

前端生产构建：`npm run build` 通过，TypeScript 检查与 Vite 生产产物生成成功，正式服务通过同源地址提供页面与 API。

## 真实网页读取试验

自研采集器成功读取利物浦官网的 [The opposition lowdown: Atletico Madrid](https://www.liverpoolfc.com/news/opposition-lowdown-atletico-madrid-0)，提取正文 4315 字符，通过网页 JSON-LD 提取 `datePublished=2026-09-08T18:28:00+00:00`。此项验证网页获取、正文与原始时间提取，未对文章事实或模型理解做评价。试验资料没有加入用户真实资料库。

阿森纳官网新闻列表返回了主要依赖 JavaScript 的加载区，采集器正确拒绝将加载内容导入。BBC Arsenal RSS 与巴萨官网在本次网络环境下连接失败；不能将它们列为已验证可用来源。具体 HTML 文章页与 RSS 各有可访问性限制。

## 结果解释

本地协议模拟器用于检查 HTTP 协议、工具循环、证据回传与取消行为，不能验证任何真实模型的足球理解水平。用户没有提供 LLM 服务配置和密钥，不能把自动测试通过表述成实际模型效果已验收。

网页采集与 RSS 支持不意味着任意足球网站都可可靠读取。单个站点需要以实际结果为准，数据源及模型上线后的分析质量仍需用真实样本评估。
