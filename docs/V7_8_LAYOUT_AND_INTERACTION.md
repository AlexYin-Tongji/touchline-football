# V7.8 版式与交互修正

这一版修掉编辑版改版（`edaec35`）留下的版式缺陷，并把三处被用户指出的问题改正。全部结论都来自实测 `getBoundingClientRect`，不是目测。

## 修正的版式缺陷

改版时把 5,026 行的 `v7.css` 换成 `v7-base.css` + `v7-app.css`，有几条组件仍依赖的规则没跟过来。

| 位置 | 症状 | 原因 |
| --- | --- | --- |
| 球队页主视觉 | 徽章缩成 30px、在 84px 圆环里偏左 27px | CSS 只写了 `.club-hero-crest img`，但组件渲染的是 `.crest`（默认 30px），没有覆写落点 |
| 球队页主视觉 | 有一列 0px 的死宽度 | `.club-hero` 声明 `auto minmax(0,1fr)`，两个子元素却都是 `grid-column: 1 / -1`，`auto` 轨道塌缩 |
| 三个页面 | 标题左沿错开 118px | `.assistant-page` 是 `max-width:880px; margin:0 auto`，把标题推到 x=402；动态与球队在 x=284 |
| 模型设置 | 「显示名称」与「API 协议」控件不同高 | 名称栏带 `<small>` 说明、协议栏没有，同行错开 2px |
| 窄屏球队页 | `minmax(240px,1fr)` 造成横向溢出 | 固定下限在容器只有 234px 时成为硬下限 |
| 备类补全 | `.history-toggle`、`.manage-models`、`.provider-address`、`.provider-key` 无规则 | 随旧样式表一起丢失 |

`scripts/class-audit.mjs` 现在报告 295 个 TSX 类名、0 个没有对应规则。

## 用户指出的三个问题

### 对话区被压成很窄的一截

上一版为了让页头不被推走，把对话页钉在视口高度、让中间区域内部滚动。实测在 932px 视口里对话区只剩 **428px**，而内容有 569px——读长回答要不停翻。

现在改为随文档自然增高：回答多长就有多长的可读高度，输入框跟在内容之后。实测长对话下对话区与输入框重叠量为 **0**，无内部裁剪。

吸底方案试过又撤掉了：页面只比视口高一点时，`position: sticky; bottom: 0` 会直接压在技能卡片上。宁可少一点便利，也不要遮盖内容。

新增一轮问答时只滚到**这一轮的开头**，不再滚到底——滚到底会把刚生成的长回答直接推上去，反而看不到第一段。

### 悬停抬升遮挡页头

卡片的 `transform: translateZ(14px)` 把卡片提升到独立图层，嵌在下面滚动的内容会盖过吸顶页头，页头下沿能看到穿过来的日期文字。

抬升整体移除。悬停反馈改成左侧一条 2px 红条（`scaleY` 展开）加标题变色——不动 `transform`，层叠关系保持干净，也不再有跨卡片的层叠上下文。

### 阅读弹窗过宽、无内边距

`.modal-body` 这个类在 TSX 里根本没人用，弹窗子元素直接贴着面板边缘，正文、来源行、提示条全部顶到左右边框。

- 阅读弹窗宽度 940px → **760px**，正文行长从约 60 字回到舒适的 44 字。
- `Modal` 组件用 `.modal-body` 包住子元素，左右各 24px 内边距。
