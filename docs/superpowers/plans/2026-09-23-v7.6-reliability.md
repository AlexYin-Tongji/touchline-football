# V7.6 来源恢复与球队资料实施计划

**Goal:** 落地已指定交接方案，改善新闻可读性、失败诊断、照片覆盖和动态筛选。

**Architecture:** 保留单一 main、本地数据边界和现有工具入口。来源层提供有期限的健康状态与多个可核实媒体；报告只读同事件、已固定并指纹校验的证据集合，明确呈现缺口。照片增加 Wikimedia 元数据适配器，验证身份及许可后才显示。

**Tech Stack:** Python/FastAPI/SQLite、React/TypeScript、现有 unittest 与前端行为检查。

**Spec:** `docs/V7.5_优化交接_HANDOFF.md`；`output/v75-design-panel-raw.md` 六份提案是参考材料，未验证断言须复测。

## 全局约束

- 外部原文只使用有界进程内临时缓存，不持久化；手写资料、凭据和已有结果保留。
- 不放开报告联网权限；不把同队不同事件拼为替代材料，不降低引用、私有和避剧透边界。
- 无可信照片或自由许可时留占位符，照片来源不得改写阵容事实。
- 不以一次网络失败永久禁用媒体，不修改系统 DNS、代理或证书校验。
- 自动化使用临时数据和模拟模型；联网探针限量，不调用付费模型。
- 当前完整基线：695 项测试通过（`output/v76-baseline-tests.json`）。
