# 看台 V8.1：照片可恢复性与回答质量收尾

2026-09-30 在 V8.0.0 之后完成一轮修复与体验收尾。当前交付版本 **8.1.0**，只使用 `main`，交付标签 `v8.1.0`。上一版交接见提交 `4bf67fb`，逐项进度见 [V8_PROGRESS.md](V8_PROGRESS.md)。

## 本轮修了什么

| 问题 | 结果 |
| --- | --- |
| 已核验照片永久读不回 | `_portrait_key` 从 v1 到 v2 整体换键，早先已核验的条目变成孤儿；`cached_portrait` 现在回读上一代，并给 `completed`（30 天）单独的长窗口，不再与临时结论同用 24 小时。真实库中 30 条 v1 孤儿条目已被重新读取，Courtois 的 CC BY-SA 4.0 照片成功找回。 |
| 社区照片兜底跳过最该兜底的人 | 兜底条件改为「维基媒体已给出结论（含拒绝）但社区尚未settled」；`unavailable`（查询失败）不算结论，不再把整队人在维基媒体故障期间推给限速的社区源。 |
| 无照片时没有解释 | 两个缓存都没有结论时写入 `not_yet_resolved` 与「照片来源尚未给出结论，下次更新会重新核对。」，而不是留一个没有理由的空占位。 |
| 一次失败永久移除一条动态 | 失败报告从「永久跳过」改为有界退避重试：最多 5 次，退避 15 分钟 / 1 小时 / 4 小时 / 12 小时。瞬时原因（限流、模型未配置、中途重启）不再让事件从流里消失。 |
| 来源分级失败拖垮整个动态 | `source_tier` 的 provider 注册导入失败时回落「未分类来源」，分级只是展示、不决定资格，不该以 500 收场。 |
| 回答总是排成固定表单 | `submit_answer` 对提问只强制 `status/answer/facts`；`analysis`、`unknowns` 改为可选。强制五项字段曾让每个问题都按同一形状作答。 |
| 正文粘贴接口时间戳与内部字段名 | 新增 `MACHINE_STAMP` / `INTERNAL_FIELD` 检查，正文里出现采集时间戳或 `fetched_at` 之类字段名会被拒绝并要求改成人话。引用原文不受影响。 |
| 每条回答下方的固定免责句 | 删掉「以上依据同一篇来源原文，尚未形成独立交叉核实。」这条固定后缀。规则仍在提示词里，措辞交回模型。 |
| 历史对话反复贴同一句提示 | 每轮对话只声明一次「不作为本次证据」，取代在每条历史回答前重复。 |
| 卡片预填的问题像表单 | 六张卡的预填提示从三四个枚举从句压成一句球迷会说的话；追问从「请进一步解释其中最值得关注的变化」改为「这里面哪一条最要紧？」。 |
| 中文译名 | 新增 `server/player_names.py`：查表，不音译；表里没有就保留源拼写、不猜。界面在原拼写旁显示中文名。真实皇马名单 35 人中已生效（库尔图瓦、卢宁、米利唐、阿诺德…）。 |
| 改版丢失的样式 | 补回 `edaec35` 拆分样式表时丢失的后代规则与 `<b>`→`<strong>` 改动后失效的选择器：球员详情 `dl/dt/dd`、球衣号码绝对定位、位置角标、胜平负指示点、比赛日期、卡片 `<h3>` 标题、赛季数字等。 |

## 后续必须保留的约束

1. 以 [DESIGN_PRINCIPLES.md](DESIGN_PRINCIPLES.md) 为准：整合信息、展示来源，真伪交给读者。来源层级决定措辞，不决定资格。
2. 只保留 `main`，交付前留回退标签，不改写共享历史；不修改 `football-ai-harness-loop`。
3. `prepare_claims` 仍要求本轮真正读过且当前仍可见的片段；子任务、结构化查询和维护日志不授予引用资格。比赛截止线、固定文章范围与避剧透边界继续生效。
4. 凭据只存服务端加密库；带凭据请求不能跨 HTTPS origin 重定向。密钥不回显、不进 URL/日志。`data/`、`output/`、`tmp/`、`.env` 不提交。
5. 自动测试只用临时库与本地替身；真实验收必须限量、区分测试材料。修改用户库前成对备份库和 key。
6. 来源失败是 gap，不能作为空成功；缓存不刷新采集时钟，未知来源不默认提级，身份有歧义不猜测。
7. **缓存换命名空间必须带上一代回读**，且「问过没有」不能当成「答过没有」；完成态与临时结论用不同 TTL，不要把已经核验的结果和一次限流同等对待。
8. **界面文案与字段校验一起改**：放宽提交契约（可选字段）要同步归一化缺省值，收紧正文校验要保留引用原文的豁免。
9. **样式表改动后必须重跑 `tmp/lost-rules.mjs` 与 `tmp/element-audit.mjs`**：选择器匹配不到任何元素时编译通过、测试也通过，只在 `getComputedStyle` 里现形。
10. 常驻循环关闭时要传播自身取消；处理子任务取消不能吞掉退出请求。照片公共入口必须共享去重；一个决策由完整任务生命周期统一终结。
11. provider 测试用 `snapshot/restore`、`unpaced()`；Windows 异步测试用 `IsolatedAsyncioTestCase`，临时 Store 关闭后才清理目录。

D-1 权限四层、D-2 AI 输出可校验呈现描述仍是后续扩展方向，本轮不开放生成代码执行或修改权限/白名单的入口。现行契约见 [QUALITY_AND_RUNTIME_CONTRACTS.md](QUALITY_AND_RUNTIME_CONTRACTS.md)。
