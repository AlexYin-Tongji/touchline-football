# V7.3：技能、来源、成功率与新闻写作

## 本轮定位

用户反馈成功率体感约50%，并认为正稿模板感过重。本轮先只读统计当时本机的42次真实整理记录：33次完成、9次失败，其中8次失败在完整原文核验、1次为模型接口格式错误。20次任务经历第二次核验。这个样本不等于全部使用体验，也不能拿其78.6%冒充本轮提升后的成功率。

旧记录相邻步骤时间差显示，83次生成阶段平均约15.14秒，61次核验阶段平均约3.27秒；其中可能包括调度等待。主要问题是重复生成/修复与模板引出的额外主张，不能只靠增加新闻网站或跳过核验解决。

## 三个技能与社区格式

遵循[Agent Skills格式规范](https://agentskills.io/specification)与[集成指南](https://agentskills.io/client-implementation/adding-skills-support)：三个目录都有名称与用途说明，使用小写连字符；主说明与细分流程分开，按需加载。

| 主技能 | 用途 | 兼容模式 |
| --- | --- | --- |
| team-news | 球队动态、新闻正稿、近况简报 | news_report、team_brief |
| team-information | 阵容、赛程、积分及有来源的球队资料 | team_maintenance |
| football-assistant | 问答、比赛观察、转会、战术、事件跟进 | ask、match_preview、match_review、transfer_check、tactics_explainer、event_watch |

`skill_catalog.py`负责受控路径、元信息与模式映射。模型只见三个主入口及用途，专项参考由加载器实际提供；旧会话与接口不失效。重复加载规程只返回简短确认。技能不扩展联网、球队、比赛、引用或子任务权限。

## 新闻如何改变

标题和导语先交代新消息；正文按事件关系展开，归因、数字、日期、重要细节和条件保持完整。来源限制影响判断时说明一次，不向读者汇报采集、阅读或核验过程，也不罗列与这篇新闻无关的资料缺口。

撤掉“完整稿必须另有分析或关注清单”的程序门槛。事实已经说清时可以自然结束；确有来源支持的背景、影响、争议或下一步安排仍须充分展开，不限字数或固定章节数量。字段非空不代表新闻更完整。

新闻标题、导语、事实以及实际填写的分析/未知仍逐项核验。不能用删掉必要条件、减少核心事实、降低核验判定或把摘要冒充正文来提高通过率。两组明确虚构的同事实前后样稿位于[新闻写作规程](../agent_skills/team-news/references/news-writing.md)。既有已核验成稿没有批量改写。

## 信息来源

新增实测公开入口：[BBC全足球RSS](https://feeds.bbci.co.uk/sport/football/rss.xml)与[Sky Arsenal RSS](https://www.skysports.com/rss/11670)。BBC公共索引可以跨球队复用原始元数据，随后按明确球队身份和男足一线队范围筛选。Sky本轮只添加已经验证的阿森纳入口，不猜其他球队的数字地址。

Sky的BST时区此前导致20条订阅日期全部丢失；现仅在其出版域名转换为明确偏移，不给任意无时区日期补UTC。排除音视频、直播页、明确女足/青年队报道，但保留一线队报道中提及青训出身的内容。普通词或跨队歧义简称不能单独认定球队。修正ESPN等媒体被误标成BBC的问题，新增默认源不再挤掉自定义源，保留禁用选择和重定向白名单。

德甲、西甲官方索引已探测到可解析页面，但索引日期尚不可靠，因此未默认加入近期发现；英超、UEFA页面当前解析器未取得候选，也没有把HTTP成功当新闻覆盖成功。

2026-09-22新代码经临时数据库真实读取：BBC返回86条、86条有日期，1.440秒；Sky返回20条、20条有日期，1.774秒，无索引错误。筛选后分别有2/10个阿森纳可读入口候选，不代表这些候选均已阅读全文。第二支球队复用BBC索引耗时约0.0005秒。另一轮限量正文探测已确认BBC/Sky文章可由现有解析器提取。以上是当前网络单次观察，不保证网站今后始终可用。

## 效率与正确性

- 指定多篇资料有界并行读取，返回顺序保持用户输入顺序；部分网络失败保留可用材料，权限错误仍停止。读取结束和真正取得模型请求名额后再次检查来源版本/权限。
- 核验仅去重完全相同引文、合并同一来源重叠窗口，保留独特文字、否定语境和未读区间标记，不做原文摘要。
- 核验输入明确区分来源发布时间、采集时间、已读范围与核验窗口范围；某篇截断来源不再机械拒绝另一完整来源的独立事实。
- 工具参数按解码后内容大小限制；同一中文内容使用Unicode转义不会误判超长。原字段长度、总正文大小与引文规则保持。
- 新运行记录包含生成、核验、排队和初始读取的独立指标，后续能定位阶段，避免只凭“失败一半”的印象判断。
