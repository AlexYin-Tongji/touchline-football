# 本地运行与免费托管

核验日期：2026-09-16。本轮默认选择 **本地个人版**：浏览器连接本机服务，数据在自己电脑上，不需要托管账号、银行卡或域名。运行时电脑需要开机；模型使用费用与托管费用是两件事。

## 可以选什么

| 方案 | 能否运行当前完整应用 | 费用与限制 | 适用情况 |
| --- | --- | --- | --- |
| 自己电脑 | 可以，当前默认 | 无额外托管费；程序运行时才自动更新 | 自己日常使用，最省配置 |
| Oracle Always Free 虚拟机 | 在成功获得符合额度的实例后可以 | 有免费计算与持久磁盘额度；注册通常需要手机号及银行卡验证，容量可能不足，闲置实例可能被回收 | 愿意自行管理服务器，接受免费资源限制 |
| Render 免费 Web Service | 能跑服务，但不能按当前SQLite方式可靠保存数据 | 空闲15分钟休眠；免费实例不能挂持久磁盘，本地文件会丢失；免费数据库也有期限 | 临时演示，不作为当前个人数据的长期托管 |
| Hugging Face Spaces | 不能把“CPU Basic零时价”直接理解为免费部署当前Docker应用 | 当前官方文档要求付费计划才能新建Docker/Gradio计算Space；免费静态Space不能运行此Python后端 | 本项目不采用 |

Oracle 的 Always Free 计算资源要求位于账户主区域；官方明确提醒可能缺少可用容量，也可能回收闲置实例。应只创建明确标为 Always Free 的资源，不能把试用额度误当永久免费额度。[Oracle 免费资源](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm) · [注册要求](https://docs.oracle.com/iaas/Content/FreeTier/freetier.htm)

Render 免费服务的磁盘与休眠限制，和本项目保存本机数据库的方式不匹配。[Render 免费服务说明](https://render.com/docs/free)

Hugging Face 的计算Space创建条件已经变化；硬件表的FREE标签不等于新账户可免费创建任意Docker服务。[Spaces 官方说明](https://huggingface.co/docs/hub/spaces-overview)

## 本轮你需要做的事

只需在看台里填写自己要使用的模型配置。已有配置会自动迁移，无须重新购买服务器、上传球队素材或维护抓取来源。密钥在本机加密保存，不用贴在聊天或放进GitHub。

如果未来确实需要电脑关闭后仍持续更新，再考虑免费云主机。届时先验证账户能取得免费实例，再部署；当前没有替你创建任何云端资源，也没有替你接受付款或升级订阅。可选云端运行需要把本机数据与配套加密文件成套迁移，并启用网站访问保护。

目前不添加广告。接受广告不解决后台计算、持久磁盘和账号额度等平台限制；没必要为了个人使用先接广告系统。
