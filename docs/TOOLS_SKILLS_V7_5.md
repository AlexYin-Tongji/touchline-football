# V7.5：手动、完整、可继续阅读的足球工作流

本轮按维护者要求优化工具和技能：增加欧洲、南美来源，改善读取与模型瞬断恢复，完整展示联赛积分榜和欧战赛程，提供独立球员照片工具，并取消定时处理。维护者明确授权使用现有模型凭据进行真实验收；全部测试成稿保存在隔离数据库，不写入个人动态。

## 更新的实际行为

- 一次点击启动只执行一轮，完成即结束；页面刷新、服务重启、旧跟进时间和旧自动化设置均不发起资料或模型请求。取消仍清理子任务，已经完成的内容保留。
- 新增西班牙 AS 官方 RSS、阿根廷 TyC Sports 国际足球。TyC 索引无日期时，对最多三个匹配候选读取正文核实日期，再执行近期筛选；不把未知日期当最新。
- 连接失败的媒体进入短暂主机冷却，避免同站每篇重复等待。404、解析失败不会封掉整站；来源失败会明确返回，其他成功资料继续使用。没有绕过 403 或付费限制。
- Inter 官网正文按明确文章组件与可见 DOM 提取，去除语言按钮、阅读时长、独立播客卡，保留引语作者和全部实质结尾。隐藏或付费正文不进入模型。
- 球队页提供完整所属联赛积分榜，按真实排名排列并突出当前球队。赛程包括来源确认参赛的欧冠、欧联、欧协联和欧洲超级杯；国内积分统计不混入欧战。
- `fetch_player_photos` 按当前阵容的来源身份取图，保留出处。找不到明确匹配则留空；照片请求和官网目录共享物理并发限制，取消的等待者不继续写数据，实际线程结束后才释放名额。

## 长稿处理

原流程可能只向首轮模型提供前 12,000 字，后续分页依靠模型主动请求。本轮改为先逐页读取全部可见正文，再开始写稿。

超过 8,000 字的新闻按完整段落分片，每片约 4,500–5,500 字，相邻片段只提供必要语境。最多三个真实运行器子任务并行提取重要内容，具有独立上下文、来源片段编号、取消与释放机制。提纲按原文顺序交给主任务；一个分片失败不会丢掉其他分片，主任务仍持有全文用于补足。

新闻使用独立编辑提示和 `status/title/summary/facts` 表单。实质背景、影响和未决条件写入正文，不再要求模型另填容易产生模板文字的 analysis/unknowns。程序兼容旧稿字段。相对赛季保留原文表达，新增具体年份必须有当前来源依据。

修订阶段使用 `revise_news`，只返回需要更改的标题、导语、指定正文段或新增段，程序逐字保留其他内容。无需因一两处核验反馈重新生成整篇长稿。单次生成尊重已配置的请求超时，不再为每篇新闻强制覆盖成 240 秒。

## 核验不再“一票否决”整稿

按维护者本轮追加要求，将技术核验未完成与实际内容冲突分开处理：

1. 原文实际阅读、引用片段、来源权限与版本仍由程序检查。这些边界不因模型失败而放宽。
2. 独立核验重点看标题、导语及最多四个涉及人物归属、日期数字、比分、转会或伤情阶段的核心段落，不声称逐句认证全文。
3. 中长稿另做重要内容完整性检查，与重点核验并行。它只提出有真实来源片段的补全建议，不以篇幅或逐句翻译为标准。
4. 明确冲突或重要遗漏给一次针对性补正机会；保留其他完整内容。核验漏条允许一次结构修复，模型连接瞬断只重试当前请求，不重做已执行工具。
5. 核验服务不可用、部分重点信息存疑、完整性检查未全部完成时，保留完整成稿，在导语前统一提示一次。`review_status` 与 `review_notice` 和正文一起持久保存；不把这些稿件冒充全面核实。
6. 合法初稿在检查前建立恢复点，检查阶段预留交付时间。用户主动停止仍立即取消；核验耗尽时间不应丢掉已经写好的稿件。

模型请求并发为全局 6、同一服务地址 4；报告并发 4、长稿分片并发 3。不存在每日 token 或篇数配额。请求调度仍按根任务公平轮转，等待子任务时不占模型名额。

| 项目 | V7.4 对照 | V7.5 验收 |
|---|---:|---:|
| 20 次尝试成功成稿 | 13 | 19 |
| 整批耗时 | 361.29 秒 | 218.72 秒 |
| 单次中位耗时（含失败） | 68.53 秒 | 29.20 秒 |

首次验收的 19 篇中，16 篇完成重点核对，3 篇保留统一进一步核对提示；1 篇 AS 来源临时不可读，没有调用模型凑稿。随后四篇针对性复测均成功，包括同一 AS 文章，首次失败没有删除。Sky 长稿局部修订后的复测为 75.40 秒，对照 89.75 秒；正文从对照约 3,378 字增加到约 4,790 字，保留九个实质主题。

独立审阅按完整性40、准确归因40、可读性20评分。四篇针对性复评为 Inter 97、TyC 98、AS 98、Sky 95，平均97。这个分数是明确样本上的审阅结果，不是全部媒体、任意模型或未来新闻的准确率保证。Sky仍有一处“首发踢中场”条件概括偏宽，已计入扣分；界面只标“重点信息已核对”，不声称逐句认证。

汇总文件：`output/v75-acceptance-summary.json`。尝试另外两个已配置模型时分别遇到429和生成超时，因此没有改变个人模型设置或添加自动轮换。模型额度充足也不能消除上游限流或无响应，这类情况由受限重试和明确状态处理。
